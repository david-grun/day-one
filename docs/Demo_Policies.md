# Fictional demo policies

These are explicit prototype defaults used to make DayOne runnable. They are not approved employer practice or a Philippines compliance checklist. Validate them with HR, IT, and hiring managers before a real pilot.

| Policy | Demo behavior |
| --- | --- |
| Responsibility | HR coordinates; the owner completes their own team's work. HR cannot complete an IT or manager task. |
| Reviewer | Coordinator may also be the assigned reviewer. Only that assigned active HR user can sign off. |
| Templates | Software Engineer, Sales Associate, and a visible General fallback share a baseline with explicit role-specific instructions. Intake snapshots task values; later template maintenance does not rewrite existing work. |
| Dates | Calendar-day offsets from start date; Asia/Manila date-only due dates, UTC event timestamps. Due today is not overdue. |
| Dependencies | Unmet prerequisites block both starting and completing dependent work. Blocked and overdue are derived indicators, not extra task progress values. |
| Task progress | Pending, In progress, Completed. Optional unfinished work does not block review or approval. |
| Readiness | At least one required task, all required tasks complete, and a currently valid HR approval for the preparation version are necessary for Ready. Task completion alone opens Awaiting HR review. |
| Correction | A reasoned reopening returns affected completed dependent work for revalidation, invalidates approval when required preparation is affected, and preserves history. |
| Material changes | Preview before saving. Start date, manager, role/department, arrangement, requirements, or reviewer changes invalidate approval and revalidate relevant work. General coordination notes and spelling corrections preserve it. |
| Reassignment | HR can assign HR/IT tasks within the same team with a reason. Manager tasks follow the hire's manager. |
| Cancellation | Reason required, records retained, approval invalidated, active queues/metrics excluded, further work blocked. Restoration is deferred. |
| Risk | An active non-ready hire is at risk when the start is within three calendar days or already past. |
| Reminders | In-app queues only. No external email/SMS or account provisioning is claimed. |

Equipment completion means availability and collection/delivery arrangements are confirmed; it does not presume every employee receives equipment before their first day. Manager requirements record equipment, approved applications, and the arrangement. IT confirms prepared work email and application access evidence. Never store passwords, tokens, contracts, salary, government IDs, or other sensitive employee documents in notes.

The main demonstration uses seeded earlier IT/manager completions followed by a real HR action and sign-off. Seeded history is labeled as fictional example history. Measures represent coordination and elapsed waiting; they do not prove labor savings or employee productivity.
